What this tool can do in the browser
  • PDF → HTML (text extract), TXT, Markdown, PNG/JPG of pages, or re-export PDF
  • DOCX → HTML, TXT, Markdown, PDF, DOCX (re-export as simple Word file)
  • HTML / Markdown / TXT → HTML, TXT, Markdown, PDF, DOCX
  • DOCX output: simple paragraphs from text (not full Word fidelity). Complex layout, tables, and images may be simplified.
  • Not supported: Excel/PPT, scanned-PDF OCR, password-protected files, full ODT
  • Libraries load from CDN only when needed (PDF.js, Mammoth, html2canvas, jsPDF).
