How this works
  • Default (fast): Pure browser APIs (FileReader, Image, Canvas). Works when you open this file directly or host it. Supports PNG, JPG, WebP, GIF, BMP, SVG, ICO and formats your browser can decode.
  • Advanced Engine: Loads ImageMagick WASM (~15 MB) + optional PDF.js. Unlocks TIFF, TGA, JPEG 2000, PCX, flattened PSD, PAM/PPM, XPM, WBMP, and more. PDF files render page 1. Works on GitHub Pages / any https host.
  • Nothing is uploaded.
